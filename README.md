This is the current desktop client from the verified Clinkz/DeathBringer Windows release, compatible with the current live cache, including Buster Sword. No ZIP extraction is needed.

Install **Java 19 or newer**; **Java 21 is recommended and was tested with this release**. Open the downloaded JAR with Java, or run this command in its download folder:

```text
java -Xmx1024m -Dfile.encoding=UTF-8 -jar BurialGrounds-Client-Clinkz-DeathBringer.jar
```

An internet connection is required. The client downloads game/cache data on first launch and as needed. This standalone JAR does **not** automatically replace itself with newer client versions; download a fresh JAR for client updates. Keep your existing cache/settings when updating.

## Account and world access

New players can choose **Create Account** on the login screen, complete registration, then log in with their email and password. First login includes choosing and confirming a character name. Existing accounts can sign in normally. Select **Main World** for the public server; Developer World requires local server services.

This is an early development preview. Greyhaven buildings and activities are unfinished.
