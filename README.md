# Burial Grounds - Downloads

Download the current **Create Account development preview** for Main World:

- [Windows 64-bit ZIP](https://github.com/fooliosissir-cmd/Public-Client/releases/download/preview-2026-09-29/BurialGrounds-Windows-preview-20260929.zip) - extract the entire ZIP and run Play.vbs or Play.bat. Java is included.
- [Android APK](https://github.com/fooliosissir-cmd/Public-Client/releases/download/preview-2026-09-29/BurialGrounds-Android-0.2.11-dev.apk) - Android 7 or newer. Update a compatible previous development build without uninstalling it.
- [Release notes and checksums](https://github.com/fooliosissir-cmd/Public-Client/releases/tag/preview-2026-09-29)

New players can choose **Create Account** on the login screen, complete registration, then log in with their email and password. First login includes choosing and confirming a character name. Existing accounts can sign in normally. Select **Main World** for the public server; Developer World requires local server services.

This is an early development preview. Greyhaven buildings and activities are unfinished. Both clients build and open their themed registration screens, and 17 server tests covering validation, naming and world login pass. A complete live new-account signup-to-world playthrough is not yet verified.

The Android APK is the signed development package `com.burialgrounds.client.android.dev`, version 0.2.11-dev. SHA-256 checksums are attached to the release.
