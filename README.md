## Windows

- [Download BurialGrounds.exe — Windows launcher](https://github.com/fooliosissir-cmd/Public-Client/releases/download/windows-launcher-v1.0.0/BurialGrounds.exe)

Run the EXE once. It creates your Desktop and Start Menu shortcuts, downloads the game with Java included, and opens Main World. Future Windows game updates install automatically when you open the launcher; you do not need to download another game ZIP. Your settings are kept.

The initial launcher is unsigned. Game updates are automatic; a future replacement of the launcher itself would be a separate download.

## Account and world access

New players can choose **Create Account** on the login screen, complete registration, then log in with their email and password. First login includes choosing and confirming a character name. Existing accounts can sign in normally. Select **Main World** for the public server; Developer World requires local server services.

This is an early development preview. Greyhaven buildings and activities are unfinished.
